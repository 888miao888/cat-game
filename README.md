# 🐱宝娟摸鱼🐟️ (Cat Catch)

一只叫宝娟的小猫接小鱼的摸鱼小游戏（Phaser + TypeScript + Vite，单文件自包含）。

## 🎮 在线试玩
- GitHub Pages：https://888miao888.github.io/cat-game/standalone.html

## 玩法
- 左右方向键 / A D 或鼠标拖动移动宝娟（手机触屏也可以）
- 接小鱼 +10 分，金鱼 +50 分，连击有加成（x2 +10、x3 +20...）
- 盲盒 🎁：30% 变大 / 30% 加速 / 40% 无敌（持续 5 秒，无敌时炸弹不扣血）
- 难度递增：等级越高，掉得越快、炸弹越来越多
- 3 条命；退出时（ESC / 切后台 / 退出按钮）有防误触确认，可 3 秒倒计时继续
- 排行榜记录最高分（本机）
